# MakeSmile

**MakeSmile** is a web application that makes it easy for individuals to donate used or old books and toys to the Rotaract Club. Designed with simplicity in mind, it allows users to contribute books with just a few clicks—no hassle, no clutter.

The platform helps channel these donations to children and communities in need, supporting the Rotaract Club’s mission to promote education and reduce resource waste. MakeSmile not only gives books a second life but also turns simple acts of giving into lasting smiles.

--- 
##  Features

-  Donate used/old books and toys easily
-  Support educational outreach by the Rotaract Club
-  Simple and clean user interface
-  Separate frontend and backend structure
-  Secure and efficient backend handling

 ## 🛠 Tech Stack

- **Frontend:** Vite + React.js
- **Backend:** Node.js + Express.js
- **Database:** MongoDB

## 🧑‍💻 Getting Started

### Prerequisites

- Node.js installed
- npm or yarn

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/makesmile.git
cd makesmile
```
### 2. Start the Frontend
```bash
cd client
npm install
npm run dev

```
### 3. Start the Backend
Open a new terminal window:
```bash
cd server
npm install
npm start
```
Runs on: http://localhost:3000/ (or your configured port)


## 🔮 Future Scope

MakeSmile has the potential to grow into a more powerful and community-driven donation platform. Here are some of the future enhancements planned:

- 🗺️ **Map Integration:** Display a map showing nearby NGOs based on the user's location to help them find the closest donation centers with ease.

- 🔔 **Donation Reminders:** Implement email or app notifications to remind users of recurring donation opportunities and upcoming book drives.

- 📊 **Impact Dashboard:** Introduce a dashboard for both users and administrators to view donation statistics, including number of books donated, beneficiaries reached, and monthly contribution trends.

- 📃 **Certificates of Contribution:** Generate downloadable appreciation certificates for users to recognize and encourage continued participation.

- 📱 **Mobile App Extension:** Develop a mobile version of MakeSmile to increase accessibility and encourage more on-the-go donations.
